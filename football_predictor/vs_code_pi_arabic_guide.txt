============================================
دليل استخدام pi مع العربية في VS Code
============================================

المشكلة:
---------
VS Code Terminal يستخدم xterm.js
xterm.js ما يدعم العربية (RTL) - الحروف تنقلب وتنفصل
مثلاً: "مرحبا" تطلع "ا ب ح ر م" أو "ابحرم"

الحل النهائي: RTL Terminal Extension
--------------------------------------
إضافة متوفرة في سوق VS Code. أول تيرمنال يدعم العربية صح.

============================================
الخطوة 1: تأكد من تثبيت الإضافة
============================================
مسبقاً: khalid-alzahrani.ar-terminal (v0.3.4)
لو عايز تنزلها يدوياً:
  code --install-extension khalid-alzahrani.ar-terminal

============================================
الخطوة 2: افتح RTL Terminal
============================================
في VS Code:

  الطريقة الأولى (أسرع):
    Ctrl + Shift + T
    → بتفتح RTL Terminal جديدة

  الطريقة الثانية:
    Ctrl + Shift + P
    → اكتب "RTL Terminal: New Terminal"
    → Enter

  الطريقة الثالثة:
    Ctrl + `  (تيرمنال عادي)
    → اضغط على السهم 🔽 جمب اسم التيرمنال
    → اختر "RTL Terminal"

============================================
الخطوة 3: شغل pi
============================================
في RTL Terminal:
  pi
  Enter

وبكذا العربية تطلع معك مضبوطة 💯

============================================
مقارنة التيرمنالات
============================================
| التيرمنال            | العربية | الطريقة              |
|----------------------|---------|----------------------|
| Terminal العادي      | ❌ مقلوبة | Ctrl + `            |
| RTL Terminal         | ✅ صحيحة | Ctrl + Shift + T    |
| CMD خارج VS Code     | ❌      | -                   |

============================================
كيف ترجع تشوف المحادثات القديمة
============================================
- اسكرول للأعلى بالماوس
- /tree  → شجرة المحادثة
- /resume → كل الجلسات السابقة
- /session → معلومات الجلسة الحالية
