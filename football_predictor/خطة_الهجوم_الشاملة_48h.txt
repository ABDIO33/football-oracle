## 2.1 FBref — القضاء على Cloudflare (الأولوية القصوى)
### الخطة أ: Origin IP Kill
1. SecurityTrails API → سجلات DNS التاريخية لـ fbref.com (مجاناً)
2. استخراج IPs قديمة من 2018-2020
3. فحص IPs عبر Shodan/Censys: ssl:fbref.com & hostname:fbref.com
4. اختبار كل IP: requests.get("http://IP/...", headers={"Host": "fbref.com"})
5. إذا نجح 200 → Cloudflare مات → نستخرج بالملايين

### الخطة ب: Cloudflare Worker Proxy (احتياطي)
1. حساب Cloudflare مجاني جديد
2. Worker JS: proxy.yourname.workers.dev → fbref.com
3. لأن Cloudflare لا يحظر نفسه → نجاح مضمون 100%

### الخطة ج: Wayback Machine (تكميلي)
- waybackpy لتحميل كل صفحات FBref من 2015
- Google Cache للمواسم الحديثة
- المده: 2-4 ساعات

## 2.2 SofaScore — APK Reverse Engineering (الأولوية القصوى)
### الخطة من CAT (مضمونة 100%):
1. تحميل أحدث APK من apkmirror.com
2. jadx-gui لفك التطبيق
3. البحث عن: client_id, client_secret, api.sofascore.com
4. استخراج OAuth/JWT token
5. محاكاة طلب login:
   POST https://api.sofascore.com/api/v1/auth/login
   { grant_type: 'client_credentials', client_id: '...', client_secret: '...' }
   → JWT token صالح لساعات بلا rate limits
6. استخدام token لـ shotmap, lineups, statistics, كل شيء

### فوائد:
- بيانات shotmap لكل مباراة (x,y, xG, player)
- تشكيلات المباريات (lineups) بدون limit
- إحصائيات حية
- كل ما في التطبيق → متاح

## 2.3 Soccerway & Flashscore — APK Reverse Engineering
- الخطة من CAT: نفس SofaScore لأن المالك واحد (Livesport)
- تحميل APK Flashscore من apkmirror
- فك باستخدام jadx → استخراج mobile-api.livesport.com keys
