# Football Oracle — Context & Key Decisions

## Project Goal
Build the world's most accurate football exact-score prediction system (25-class: 0-0 to 4-4+) for value betting at World Cup 2026.

## Current State (Jun 26, 2026)
- **Database**: 887,041 matches, 1,101,520 walkforward states, 9,093 teams
- **81 features per match**, date range 1983-2026
- **V5 trained**: 18.51% exact (177K realistic test set, chronological split)
- **V5 production model**: `v5_model.pkl` (105 MB) — loaded automatically by `predict_match()`
- **V5 ensemble**: M5_deep=56%, M5_small=24%, xgb=12%, M5_medium=8%
- **V5 betting @30%**: 21.1% accuracy (not profitable enough)
- **V3 model (25.89%) superseded** — V5 uses 7x more data (887K vs 128K) on harder test set

## Key Files
- `MASTER_PLAN.md`: 7-day plan to #1 in the world
- `ai_team.py`: Agent team for MASTER_PLAN execution
- `train_v5.py`: V5 trainer (887K matches, 5 architectures, focal loss)
- `build_production_v5.py`: Builds `v5_model.pkl` from training artifacts
- `direct_predictor.py`: `predict_match()` — multi-model ensemble prediction engine
- `betting_pipeline.py`: Fetches upcoming matches → predicts → outputs value bets
- `models/v5_model.pkl`: V5 production ensemble (105 MB)
- `models/v5_results.json`: V5 training results (18.51%)
- `models/v3_model.pkl`: Same as v5_model.pkl (auto-loaded by predict_match)
- `models/v3_results.json`: V3 results archive (25.89% — smaller, easier test set)

## Known Limitations
- **Lineup coverage**: 8.9% (need 50%+ for +3-5% accuracy)
- **Weather**: 7.5% coverage
- **Referee**: 0% coverage
- **No GPU**: PyTorch CPU-only (17s/epoch)
- **XGBoost overfits**: 4.75x drop from random to time-split
- **No live betting support**
- **Model files >50MB**: May need Git LFS
