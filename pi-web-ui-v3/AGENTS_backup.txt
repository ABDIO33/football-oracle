# Score Exact 100 — كامل السياق

## المشروع
**Score Exact 100** — أفضل نظام توقع نتائج كرة قدم دقيق في العالم (مجاني 100%).
- قاعدة بيانات: **887,041 مباراة**، 1,067 بطولة، 4,949 فريق
- أفضل دقة توقع نتيجة صحيحة: **17.97%** (seed محظوظ) / **17.60%** (seed=42, إنتاج)
- أفضل دقة 1X2: **56.11%** (M5 منفرد)
- RPS: **0.1125** (كلما قلّ أفضل)

## الموديلات
- **5 معماريين DeepNN**: M2 (512-1024-512), M3 (256-512-256-128), M4 (512-1024-512-256), M5 (128-256-128), M6 (1024-512-256)
- **الإنتاج الحالي**: Ensemble XGBoost(5%) + M2 + M5 = 17.60%
- **محفوظ في**: `models/mlp_blend.pkl` (joblib, DeepNN + XGBoost + imputer + scaler)
- **81 ميزة**: walkforward Elo/xG (25) + إحصائيات (12) + تشكيلات/لاعبين (10) + أسعار (6) + ميزات مركبة (23) + طقس (4) + سفر (1)
